# 抱布记：时间长河首版方案（讨论稿）

日期：2026-10-27。状态：方向已初步确认；数据保存于现有服务器；具体交互及实机可行性待确认。

## 想达成的体验
在私人空间中自由漫游，偶然遇到忘记的普通日子。生活素材尽可能从已有来源收集，不要求用户每日主动打卡。记录可以包含照片、一句话、感悟和段子。

## 使用场景
1. 一次性授权连接高驰，并选择照片同步范围。
2. 新的运动和授权范围内的照片逐步进入抱布记，用户无需每条手动输入；同步时机不保证实时。
3. 小程序展示可探索的时间世界，点开某个瞬间看到真实来源、时间与照片或活动；可以顺时间回看前后。
4. 可手动补一条文字或照片，也可隐藏、删除已收录项目；自动收录范围可关闭或调整。
5. 重装、更换设备或恢复备份后，验证数据仍可读取。

以上为目标流程，权限、后台持续运行与服务可用性须在实际设备验证。

## 首版范围
- 高驰运动摘要：官方 OAuth + MCP 读取、定时查询与去重；获取路线的能力/粒度另行验证。连接不可用时通过用户自行导出的 FIT 文件导入。历史深度以实际接口结果为准。
- 安卓配套工具：对明确授权的照片范围建立索引并上传，增量与断点重试；选择照片范围、同步状态、暂停；只有必要元数据，地点默认为关闭。不同安卓版本、系统杀后台与权限政策影响自动同步，不能保证实时或全相册。
- 微信小程序：单用户登录、时间漫游、查看单条记录、手动补充、按日期跳转、隐藏/删除。探索世界先验证交互，不承诺复杂三维动画。
- 现有账户与业务数据：保留既有数据库和账单、健身入口及用户改动；新功能先在隔离测试环境实现；迁移前备份验证与回退，旧功能如何呈现须另行确认。
- 未来：个人/双人共同空间、阅读、音乐、消费、聊天导入；第三方服务是否能自动接入以官方能力与许可实测为准。

## 数据与部署方案（用户已选择现有服务器）
用户选择使用现有服务器保存回忆数据。安卓负责同步，高驰读取服务和后端负责记录索引及照片，小程序负责显示。上线前核实服务器容量、访问、权限和备份恢复能力；不假设现有服务器已适合存储私人照片。
数据模型至少包含：记录 ID、用户 ID、来源、来源 ID、发生时间和时区、类型、内容引用、隐藏/删除状态；按用户+来源 ID 去重。原始文件与元数据分开管理。来源中无法获得的事实应明确留空，不推断当时心情。
安全目标：用户身份隔离、传输加密、来源独立授权及撤销、敏感凭据由系统安全机制保护、日志不输出敏感内容、导出和删除（含文件及可控备份策略）、可恢复备份。具体部署以选定环境验证为准。

## 分阶段开发与验收
1. 技术验证：隔离环境测试高驰 OAuth 连接、读活动、数据范围和路线；安卓选取照片/授权范围与后台可用性；记录失败原因，不操作线上数据库。
2. 后端：新增独立的数据结构、接口与迁移，建立来源连接、幂等同步、媒体访问、分页及备份恢复；保留现有服务。
3. 安卓端：权限说明、照片范围选择、待同步队列、断网重试和用户可见状态；不同系统测试，开放手动同步兜底。
4. 小程序端：用真实或模拟数据制作可交互时间世界，提供按时间跳转和偶遇记录；用户评价后调整，支持无数据、加载失败和同步中状态。
5. 联调：测试新用户及已有用户、账号隔离、授权撤销、重复同步、断网恢复、时区、图片损坏、删除与备份恢复；微信模拟器与用户安卓手机真机均验证。
6. 发布准备：确认主体、服务类目、服务器、域名、隐私与数据权限声明，按届时微信官方规则核验；开发者工具上传体验版，真机检查，确认后提交审核，再发布。安卓安装包签名和安装渠道需要单独确认；任何实际部署或发布以确认的范围及条件为准。
