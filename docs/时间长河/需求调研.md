用户偏好探索世界与偶遇遗忘的普通瞬间。希望自动收集跑步、路线、照片、地点、音乐、阅读、消费与 AI 对话等生活痕迹；主要自用，未来可选伴侣共同空间；不想持续主动手动记日记。
现有来源：安卓、高驰手表、手机相册、微信读书、网易云音乐、微信支付、ChatGPT、DeepSeek。

## 接入核查（初步，未接入或实测）
- COROS 官方 MCP：OAuth 授权后单用户读取数据，可轮询，无 webhook；文档称不支持 GPX 路线导入导出和双向活动同步。https://support.coros.com/hc/en-us/articles/53181619102996-Build-on-COROS-MCP ，具体活动路线能否取得须实测。合作伙伴 API 需申请，可读取 FIT，https://support.coros.com/hc/en-us/articles/53181766856724-Partner-API-Access 。手动 FIT 导出 https://support.coros.com/hc/en-us/articles/360043975752-Exporting-Workout-Data-and-Uploading-to-3rd-Party-Apps
- 安卓原生相册扫描存在权限范围限制，后台运行和上传受系统限制；不能推断小程序可自动扫描。https://developer.android.google.cn/training/data-storage/shared/media?hl=en
- 后台定位需安卓权限且后台更新受限，https://developer.android.com/develop/sensors-and-location/location/background ；先探索运动路线和照片元数据可用性。
- 微信读书第三方开源工具支持划线导出 https://github.com/gnixner/weread-import ，非官方接入，有失效或登录态依赖风险。
- ChatGPT 可用户手动申请数据导出 https://help.openai.com/en/articles/7260999-exporting-your-chatgpt-history-and-data 。不能据此承诺自动同步历史。DeepSeek 尚未核实。
- 网易云音乐与微信支付的面向个人账户自动同步官方接口尚未核实；不能承诺。微信支付手动导入须验证当前实际格式与流程。
- 灵感参考： https://github.com/immich-app/immich （自托管照片）及 https://github.com/coroslab/COROS-MCP （高驰官方 MCP）。未安装或测试。
