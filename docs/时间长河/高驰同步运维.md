# 高驰同步运维准备（尚未上线）

> 后续增量：worker 现在要求已存在且为 `active` 的 `source_controls` 行，并使用账户来源级租约与代次；缺表、未配置、暂停或租约变化均不能同步。该表不是高驰授权或账号映射证明，不要为了运行 worker 直接在生产数据库手工插入活动状态。此功能尚未部署，需先建立经过验证的授权与控制行创建流程、迁移和回退。

本文件记录开发及部署前验证，不代表已启用定时任务。真实授权信息、账号、照片、运动记录和令牌都不能写入本仓库、提交记录或日志。

## 已验证的边界

- 高驰官方 MCP 支持独立授权并读取运动记录，当前已在本机临时环境验证；腾讯云尚未获得抱布记的同步授权。
- 本次通过当前会话中的 COROS 连接器做了有限范围只读检查：返回记录的数量标头和解析器所需字段格式匹配；未将记录或凭据写入项目。此会话连接不能替代抱布记服务器上的独立授权，也不证明账户映射。官方接口说明见 [COROS MCP 工具指南](https://github.com/coroslab/COROS-MCP/blob/main/docs/en/tools.md)。
- `backend/coros_worker.py` 要求明确指定数据库、用户 ID、官方辅助程序路径和仅本人可访问的凭据目录。默认读取最近七天。中断超过 30 天后，普通定时任务停止；经排查后可显式传入 `--recover`，每次按最多 30 天分段补读，最长处理 366 天。
- 同步同时持有账户来源级有限期数据库租约和凭据目录文件锁；每次提交前在 SQLite 写锁中核对权限、代次、租约与有效期，回忆和检查点同事务提交。暂停、恢复或回忆导入改变代次并使旧任务无法写入。返回格式异常、可能截断或时间范围不符时不导入，也不推进检查点。
- 若日期范围返回条数达到请求上限，worker 会缩小范围重试，直至可确认该段未满额；单日仍满额时停止，不能声称该日数据完整。每个完整分段单独提交检查点，失败后从已提交进度重试。运动记录保留标题以及可识别的时长和公里数，不保存上游位置字段；已有记录不会自动用新摘要覆盖。
- 租约默认 120 秒，按本机系统时间计算，单次上游请求超时 60 秒；崩溃后租约到期可接管，旧租约不能提交或删除新的租约。时间跳变、SQLite 繁忙及耗时过长会导致任务停止，需要监控，不适用于未经设计的多主机部署。
- 暂停会阻止新任务和在途任务提交；已经发出的请求可能完成、辅助程序可能已刷新凭据。恢复只是允许既有配置尝试同步，不验证授权有效，更不等于重新授权或撤销授权。设置页的“已允许同步”同样不是连接成功证明。停止旧版本 worker 是上线和恢复的必要条件，旧代码与绕过协调层的直接导入函数不受此保护。
- 恢复准备工具对含 `source_controls` 的备份清除租约、递增代次并将来源暂停；缺表的旧备份不会自动启用来源。恢复副本仍须进行迁移、验证、备份与审查，不能自动切换线上。
- 辅助程序若在失败时删除 token，worker 会尽力恢复之前的副本；不会覆盖新 token。旧 token 可能已经过期或撤销，需要重新授权。

## 部署前准备

1. 先备份真实数据库并验证恢复；确认账号映射，防止把数据写入错误用户。用隔离环境完成迁移和测试。
2. 官方辅助程序必须单独获取、审核并固定版本；确认许可证和完整性，不把未经核验的临时脚本直接用于生产。来源：[高驰官方项目](https://github.com/coroslab/COROS-MCP)。
3. 在服务器上使用服务账号专有目录，目录权限 `0700`、token 文件权限 `0600`；授权必须通过高驰官方页面，严禁在聊天或命令行参数输入密码。绝不把本机临时凭据作为可靠长期存储。
4. 配置私有环境文件，只允许服务账号读取，明确设置 `DATABASE_URL` 和 `BAOBU_USER_ID`。在隔离副本上运行单次同步，检查授权失败、网络中断、恢复后去重、隐藏和删除的行为；真实服务器的首次写入需在上线前明确确认。
5. `deploy/examples/` 中仅为 systemd 服务及定时器示例，须根据服务器实际路径和安全配置审查后才能安装。核对同步返回值和系统日志中不含私人记录及凭据。
6. 数据库备份需要包含 `sync_states`、`memories` 和 `memory_suppressions`；应用导出/导入有自己的规则。未来照片文件必须独立备份并测试恢复，数据库快照不包含照片。

### 授权与只读查询预检

仓库新增 `backend/coros_preflight.py`，为隔离环境及服务器部署准备提供只读查询入口。操作人员须先独立审核官方辅助程序、记录其 SHA-256，并在运行机器的私有目录完成高驰官方授权；目录和令牌权限要求与 worker 相同。以下命令中的路径、账户 ID 和摘要均为操作者在目标机器上自行确认的值，不是默认配置：

```sh
python backend/coros_preflight.py --database /absolute/path/to/database.db \
  --user-id ACCOUNT_ID --helper /absolute/path/to/reviewed-helper.py \
  --helper-sha256 REVIEWED_SHA256 --state-dir /absolute/path/to/private-state
```

预检以只读方式确认抱布记账户存在和本地来源许可状态，核对辅助程序文件摘要，在与 worker 相同的凭据目录锁内查询最近七日，并验证响应格式和日期范围。只输出固定状态，不输出记录、凭据、路径或原始上游结果，也不写回忆、检查点或来源控制记录。摘要只能证明文件与操作者提供的值一致，不能证明来源可信或阻止有权修改该文件的进程在核验后替换它。高驰辅助程序可能刷新或更新其私有凭据、登录状态及工具缓存；因此这不是完全无副作用的请求。

预检成功不证明指定高驰账户属于指定抱布记账户；需要单独完成官方授权和用户确认的账户映射。`source_status` 可能为 `schema_missing` 或 `unconfigured`，并不表示已绑定；`not_capped` 只说明七日查询没有达到本次返回上限，不证明历史完整。新代码和预检尚未在生产服务器部署或实际执行。

## 安全故障代码

日志只包含固定故障代码，不包含第三方返回内容：

- `provider_or_authorization_error`：检查网络或重新授权。
- `credentials_need_review`、`credential_or_helper_missing`、`credential_permission_denied`：检查服务账号权限与授权状态。
- `invalid_or_incomplete_response`：接口格式、条数上限或日期范围异常，不应推进同步进度。
- `recovery_required`：同步间隔超过 30 天，需要检查授权和数据后人工运行 worker 并加上 `--recover`。每段成功后单独提交；失败可重试。超过 366 天、单日达到返回上限或服务不支持历史范围时仍需人工调查，不要重置进度后声称数据完整。
- `sync_already_running`：同账户同来源或同凭据目录已有同步进程。
- `source_paused_or_changed`：来源未配置或暂停、代次发生变化、租约失效或被其他任务接管；在核对状态和授权前不要强制重试。
- `internal_error`：检查服务、数据库和部署配置；不要为调试将原始数据或令牌写入日志。
