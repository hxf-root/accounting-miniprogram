# 高驰同步运维准备（尚未上线）

本文件记录开发及部署前验证，不代表已启用定时任务。真实授权信息、账号、照片、运动记录和令牌都不能写入本仓库、提交记录或日志。

## 已验证的边界

- 高驰官方 MCP 支持独立授权并读取运动记录，当前已在本机临时环境验证；腾讯云尚未获得抱布记的同步授权。
- `backend/coros_worker.py` 要求明确指定数据库、用户 ID、官方辅助程序路径和仅本人可访问的凭据目录。默认读取最近七天。中断超过 30 天后，普通定时任务停止；经排查后可显式传入 `--recover`，每次按最多 30 天分段补读，最长处理 366 天。
- 同步持有进程锁；回忆与检查点在一个事务中提交；重复、隐藏和删除记录按约定处理。返回格式异常、可能截断或时间范围不符时不导入，也不推进检查点。
- 辅助程序若在失败时删除 token，worker 会尽力恢复之前的副本；不会覆盖新 token。旧 token 可能已经过期或撤销，需要重新授权。

## 部署前准备

1. 先备份真实数据库并验证恢复；确认账号映射，防止把数据写入错误用户。用隔离环境完成迁移和测试。
2. 官方辅助程序必须单独获取、审核并固定版本；确认许可证和完整性，不把未经核验的临时脚本直接用于生产。来源：[高驰官方项目](https://github.com/coroslab/COROS-MCP)。
3. 在服务器上使用服务账号专有目录，目录权限 `0700`、token 文件权限 `0600`；授权必须通过高驰官方页面，严禁在聊天或命令行参数输入密码。绝不把本机临时凭据作为可靠长期存储。
4. 配置私有环境文件，只允许服务账号读取，明确设置 `DATABASE_URL` 和 `BAOBU_USER_ID`。在隔离副本上运行单次同步，检查授权失败、网络中断、恢复后去重、隐藏和删除的行为；真实服务器的首次写入需在上线前明确确认。
5. `deploy/examples/` 中仅为 systemd 服务及定时器示例，须根据服务器实际路径和安全配置审查后才能安装。核对同步返回值和系统日志中不含私人记录及凭据。
6. 数据库备份需要包含 `sync_states`、`memories` 和 `memory_suppressions`；应用导出/导入有自己的规则。未来照片文件必须独立备份并测试恢复，数据库快照不包含照片。

## 安全故障代码

日志只包含固定故障代码，不包含第三方返回内容：

- `provider_or_authorization_error`：检查网络或重新授权。
- `credentials_need_review`、`credential_or_helper_missing`、`credential_permission_denied`：检查服务账号权限与授权状态。
- `invalid_or_incomplete_response`：接口格式、条数上限或日期范围异常，不应推进同步进度。
- `recovery_required`：同步间隔超过 30 天，需要检查授权和数据后人工运行 worker 并加上 `--recover`。每段成功后单独提交；失败可重试。超过 366 天、单段超过返回上限或服务不支持历史范围时仍需人工调查，不要重置进度后声称数据完整。
- `sync_already_running`：已有同凭据目录的同步进程。
- `internal_error`：检查服务、数据库和部署配置；不要为调试将原始数据或令牌写入日志。
