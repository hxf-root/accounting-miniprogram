# 抱布记项目交接

更新日期：2026-10-27。本文记录本阶段最后已核实状态；再次开始前先检查仓库和微信后台，因为状态可能已变化。

## 产品方向

把生活中的素材尽可能自动收集到个人空间，以时间长河的方式自由浏览、偶遇过去的普通瞬间。用户希望默认仅自己可见，未来可能与伴侣共同记录。目标数据包括高驰跑步与路线、安卓照片、地点、微信读书、网易云音乐、微信支付和 AI 对话。优先使用正规授权和允许的导出方式；尚未验证的平台能力不得当作已实现。

用户希望减少手动记录，安卓照片默认只同步用户选定的相册，并可调整范围。项目资料与代码保存在 Git 并推送 GitHub；真实私人数据计划保存于现有腾讯云服务器。原记账、健身前端入口已按用户要求移除；原服务器历史数据未删除。

## 当前可运行内容

- 小程序可免登录进入首页及时间长河。未连接账户时显示明确标记的虚构示例；已有账户可在“我的”连接。真实服务器数据仍受身份验证保护；免手动操作且安全的本人识别尚未实现。
- 时间长河代码支持显示服务器回忆与稳定游标分页；服务器端相关更新还没部署。该游标不是固定快照，分页时新增更早数据可能出现在后续页。
- 已上传微信开发版本 `0.1.0`，对应小程序代码提交 `27d4f1c`。上传不代表正式发布。此前尝试通过内置浏览器提交审核时页面读取超时；用户随后自行打开过审核页面，但是否已提交、审核及发布状态未确认，恢复时应先检查公众平台，避免重复提交。用户明确表示可跳过手机测试，不能把这描述为已做真机测试。
- 最新代码提交包含高驰同步 worker、去重、删除标记、检查点及长间隔恢复原型；曾用用户单独授权的高驰会话做只读联调及内存数据库导入验证。真实数据没有写入服务器，凭据在临时位置，不应假设仍有效或可用于生产。
- 照片同步计划和本地文件存储是互相独立的原型，未接安卓、HTTP、数据库或小程序。文件存储未校验图像格式，也未移除 EXIF；不具备生产级备份、授权、配额和崩溃清理。

- 服务器曾只读检查健康、磁盘空间及一份 SQLite 备份完整性；这些结果会过期，不等于完成恢复演练，也不保护照片文件。部署前须重新核验并完成恢复与回退准备。

## 继续开发的建议顺序

1. 确认微信后台版本、审核与发布状态；不要重复发布。核查用户本地开发工具设置，不覆盖 `project.private.config.json`。
2. 为服务器回忆访问设计安全的免手动登录身份绑定；验证用户隔离、授权撤销及失效处理。不得为了免登录开放私人数据。
3. 高驰模块：核对官方辅助程序来源和许可证、固定版本，完成隔离环境的数据库备份恢复、账号映射、授权续期、断线恢复、监控及回退验证，再准备部署和定时同步。
4. 照片模块：准备安卓工具链；验证选定相册与系统目录权限之间的映射、权限撤销和后台行为。设计上传接口和受控文件存储，完成图像类型与大小校验、EXIF 隐私处理、配额、用户隔离、数据库/文件一致性、备份恢复、删除和真实设备验证。
5. 继续实现并验证时间浏览、隐藏/删除、必要时手动补充，以及数据源独立连接、同步状态和暂停。读取、音乐、消费、AI 对话及位置数据分别研究官方接口或经用户同意的导出路径，按独立模块开发。
6. 联调、审查隐私声明和服务器安全配置；按用户意愿及发布条件安排测试、部署和发布。线上写入、部署、上传与发布状态必须分别记录，不能以原型或测试冒充上线。

## 重要边界

本仓库是公开仓库。不要提交真实照片、定位、运动记录、聊天内容、账单、账号密码、令牌、含敏感信息的后台链接或二维码。`project.private.config.json` 是用户本地开发者工具配置，目前有未提交改动，保留在本机，不随交接提交。若临时授权文件不再存在或授权已过期，重新走官方授权，不要求用户发送密码或私钥。
